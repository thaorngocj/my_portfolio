CREATIVE PORTFOLIO — WEB TEMPLATE
==================================
Mẫu website được chuyển thể theo đúng phong cách ảnh đầu: giấy kẻ ô trắng, chữ đỏ viết tay, tiêu đề PORTFOLIO lớn, điểm nhấn lát cam và các chi tiết doodle.

CÁCH MỞ
1. Giải nén file ZIP.
2. Mở thư mục creative_portfolio_web.
3. Mở index.html bằng Chrome / Edge.

CÁCH CHỈNH SỬA
- Sửa nội dung, tên, trường, kỹ năng, dự án và thông tin liên hệ trong index.html.
- Thay link href="#" bằng link GitHub, LinkedIn, demo thật.
- Chỉnh màu sắc, font, khoảng cách trong style.css.
- Menu mobile đã được tích hợp trong script.js.

LƯU Ý
- Website dùng HTML, CSS, JavaScript thuần; không cần cài Node.js.
- Google Fonts cần internet; nếu offline sẽ dùng font dự phòng.
- Các hình minh họa dự án hiện là mockup CSS, có thể thay bằng ảnh chụp màn hình dự án của bạn.
